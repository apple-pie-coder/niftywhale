NiftyWhale

Trust this Pi's certificate

The connection to NiftyWhale is encrypted with a certificate from your own Pi, not from a public company, so each device has to trust the Pi once. Until it does, the address bar shows red and Face ID can't be used. It takes a minute.

Download the certificate
  1. Open this page in Safari (other browsers on iPhone can't install certificates) and tap Download the certificate, then Allow. You'll see "Profile Downloaded".
  2. Open Settings → General → VPN & Device Management, tap Caddy Local Authority – 2026 ECC Root, then Install (enter your passcode), Install again, Done.
  3. The step most people miss: open Settings → General → About → Certificate Trust Settings and turn on Caddy Local Authority – 2026 ECC Root, then Continue.
  4. Close the NiftyWhale tab in Safari (swipe it away) and open https://pandorasbox.local:5443 again.

Installed but still red? Step 3 is still off. And open the app by its name, pandorasbox.local: by IP address the lock shows too, but Face ID only works with the name.

  1. Click Download the certificate and open the downloaded file. Keychain Access opens and adds it to the login keychain.
  2. In Keychain Access, find Caddy Local Authority – 2026 ECC Root (search for "Caddy") and double-click it.
  3. The step most people miss: open Trust, set When using this certificate to Always Trust, close the window and enter your Mac password.
  4. Quit the browser completely (⌘Q) and open https://pandorasbox.local:5443 again.

Firefox keeps its own list: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, choose the file and tick Trust this CA to identify websites.

Or in Terminal, in one go:

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/niftywhale-root-ca.crt

  3. Reopen https://pandorasbox.local:5443. If .local names don't open on your Android, use https://192.168.1.50:5443.
  1. Download the certificate and double-click it, then Install Certificate….
  2. Choose Local Machine, then Place all certificates in the following store → Trusted Root Certification Authorities, Next, Finish.
  3. Restart the browser and open https://pandorasbox.local:5443.

Done when the address bar shows a lock with no warning. Then sign in.
